# Đồ án Web Bán Bánh Ngọt

Dự án sử dụng kiến trúc Monolithic với Node.js (Backend) và React (Frontend).

## Cấu trúc thư mục

- `backend/`: Mã nguồn máy chủ Node.js + Express.
- `frontend/`: Mã nguồn giao diện React + Vite.

## Công nghệ sử dụng

- **Backend:** Node.js, Express, PostgreSQL.
- **Frontend:** React, Vite.
- **Database:** PostgreSQL.
- **Lưu trữ ảnh:** Cloudinary.

## Hướng dẫn chạy dự án

### 1. Cài đặt Backend
```bash
cd backend
npm install
npm run dev
```

### 2. Cài đặt Frontend
```bash
cd frontend
npm install
npm run dev
```

## Ghi chú
- Cấu hình biến môi trường trong file `backend/.env`.
